# Solution Video Storyboard (≤5 min)

Record last, once everything else is done — but write the script now so
recording is just execution.

| Time | Section | Content |
|---|---|---|
| 0:00–0:45 | Problem + baseline | State the user/bottleneck in one sentence. Show baseline running once — the naive approach and its limitation. |
| 0:45–3:00 | One realistic run, start to finish | Run the advanced solution end-to-end on a real/representative case. Narrate what's happening, not just what's on screen. |
| 3:00–3:45 | Final comparison | Show the `eval/harness.py` comparison table. Call out the specific numbers that matter. |
| 3:45–4:30 | Changelog highlights | The 2–3 changelog entries that mattered most — what evidence triggered each. |
| 4:30–4:50 | Biggest win + one thing removed | The single change that contributed most to the improvement. One experiment you tried and cut — and why. |
| 4:50–5:00 | Close | Main failure mode, one sentence. |

Recording notes:
- Screen-record the actual terminal/run, not slides describing it.
- Keep narration tight — write out the script text per section below once
  the real results exist, then read from it.
